# Multi-Monitor Bar media

- `../../preview.png`: 1536 × 1024 edited settings preview, made with the built-in imagegen tool from a desktop capture of the installed plugin.
- `minimal-bar.png`: 1080 × 30 unretouched capture of the DP-3 bar.
- `secondary-bar.png`: 1920 × 30 unretouched capture of the HDMI-A-1 bar.

Captured on Kvant on October 5, 2026 UTC (October 4 in Chicago). The installed
configuration had DP-1 as the Full primary display and DP-3 and HDMI-A-1 as
Minimal secondary displays. The captures use the host's active theme and
workspace labels. No monitor settings were saved to prepare the media.

The preview uses generated presentation artwork and a reconstructed rendering
of the captured settings interface, with its empty vertical area shortened.
It is not a pixel-exact screenshot. The bar strips show the actual installed
appearance. The captured installation and the current repository can differ;
this media does not extend the compatibility claims in the main README.

Imagegen brief: retain only the settings panel; remove other applications,
conversation text, desktop status and pet; preserve the monitor list, modes,
position, transparency and stock-source controls; shorten the empty space;
place it on a dark violet landscape with “Omarchy”, “Multi-Monitor Bar” and
“Full, Minimal or Hidden — per display”; mark it “Edited desktop capture”.

The media is distributed under the repository's MIT license. Raw desktop
captures containing other apps are excluded from the repository.
